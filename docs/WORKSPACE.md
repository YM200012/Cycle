# 器材与目标 · v0.6.0

## 器材

在“目标与器材”添加自行车、跑鞋等器材，并选择适用运动类型。活动编辑页可分配同类型器材；停用后保留历史使用统计，但不能再新分配。

累计里程为“初始里程 + 关联已完成活动距离”，使用时间与次数也只取已完成活动，计划和已关联但仍保留的计划目标均不重复计入。初始里程应只补充没有录入本机的历史使用，避免重复。

维护间隔由用户填写。记录维护时使用当前累计里程作为维护基线，并保存所填日期和内容。之后显示维护后的新增里程和距下一里程间隔的差值；它不是机械安全诊断或基于使用条件的寿命预测。维护日期可补记，但基线始终是记录时本机累计里程，不会自动倒推历史表读数。

修改或删除实际活动后，累计使用量重新计算；累计里程低于维护基线时，维护后里程下限为零。删除器材会解除活动引用、删除器材与维护记录，保留所有活动。

## 比赛与训练目标

目标包含日期、运动类型、A/B/C 优先级，以及可选的目标距离、目标时间和备注。目标作为独立标记显示在日历，不创建实际活动或训练负荷。

完成后可主动关联同运动类型的已完成活动，每条实际活动最多关联一个目标。界面分别展示目标与实际数值，不自动推断是否达到目标；仅过去目标日期而未关联活动，也不会伪装成已完成。

删除目标保留实际活动；删除实际活动会解除目标关联。改变已关联活动的类型或完成状态前需先解除目标关联，以保持引用一致。

## 数据

完整 JSON 备份包含器材、维护记录、目标及活动引用。旧备份缺少器材与目标字段时按空列表恢复；有错误引用或无效字段的备份整体拒绝，不会部分替换。新版本备份应由相同或更新版本恢复。
