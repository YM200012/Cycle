# 周期计划与执行跟踪 · v0.5.0

## 使用

1. 在“训练库”建立常用训练，填写步骤和 FTP 目标强度。
2. 打开“周期计划”，新建 1–52 周模板。填写第几周、第几天，选择训练库模板并添加，最多 500 项；同日可安排多项。
3. 第 1 周第 1 天对应安排时指定的起始日期，不强制为周一。计划保存每项训练的内容快照；随后修改或删除训练库模板不改变周期计划。
4. 点击“安排到日历”并指定起始日期，一次创建整个周期。之后编辑周期模板不会更改已安排内容；同一模板和起始日期存在安排时不能重复创建。
5. 在“查看执行”中主动关联已导入或手动记录的实际活动。须为相同运动类型，允许不同日期完成；每条实际活动只能关联一次。另一种方式是在计划详情中“标记完成”，随后编辑为实际数据。
6. 执行页分别显示原始目标和实际时长、负荷。关联活动不会覆盖原计划目标，也不会重复增加体能曲线的实际负荷。
7. “撤回未执行安排”仅删除仍为计划且没有关联实际活动的条目。手动完成记录、已关联计划以及所有实际活动保留。删除周期模板也不会删除已安排记录。

## 数据规则

- 已安排条目的 `planOrigin` 保存模板、批次、原计划日期、起始日期与原始目标。日历改期及普通编辑不重写这些快照。
- 活动的 `completionId` 关联实际活动。修改类型或完成状态不得使关联失效；需要先在执行页解除关联。关联操作仅通过执行接口修改。
- 删除实际活动会解除对应关联，目标重新成为待执行；删除计划目标不会删除实际活动。
- 已关联的计划在日历仍显示，卡片标明“已关联”，不计入待完成计划的月/周统计。实际活动单独显示和计入训练量。
- 总执行数显示当前已完成 / 全部安排；到期执行率只包含当前安排日期不晚于统计日期的目标，且实际活动日期须不晚于统计日期才计完成。没有到期目标显示为空。逾期指当前未完成且安排日期早于统计日期；今日、未来单独显示。
- 统计基于当前数据与改期后的日期，不是历史修改快照；当前已完成条目的状态仍显示已执行，尽管其实际日期可能晚于历史统计日。撤回或删除后统计分母会相应减少。
- 计划与实际不自动按日期匹配。手动标记完成使用原计划数值，需按实际情况修正；它不等于设备测量。
- JSON 完整备份保存周期模板、快照和关联。旧备份没有周期模板字段时按空模板恢复；存在无效引用的备份会整体拒绝，不会部分替换数据。包含新字段的备份应由 v0.4 或更新版本恢复。

## 当前范围

本版实现多周计划的组合、安排和执行记录。高级训练构建与骑行 ZWO 导出已加入；自动周期编排、训练目标判定、更多设备训练格式及云端教练协作仍待实现，未宣称与原站所有规划功能一致。
