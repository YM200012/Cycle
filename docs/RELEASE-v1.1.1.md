# Cycle 1.1.1

本版将 AI 活动复盘改为可追问的对话，并改进桌面界面。

- 在已完成活动的详情中选择「AI 复盘」，可查看训练摘要、生成分析并继续追问。问答按活动保存在本机，支持重新打开和清空。
- 分析使用功率、心率和区间数据解释训练执行情况，并给出下次可检验的调整。标题、加粗、列表和表格会正常排版。
- 在「设置 → AI 活动复盘」配置 API 并选择模型。训练备份和安装包不包含 API 密钥，训练备份也不包含复盘对话。
- 精简界面样式，修复快速切页时旧请求覆盖当前页面的问题，以及窄窗口裁掉复盘按钮的问题。

在 macOS Apple Silicon 上，先退出旧版 Cycle，再将解压出的 `Cycle.app` 放入「应用程序」并替换旧版。原有训练数据沿用本机数据目录。

174 项自动化测试通过；多轮请求、界面交互和排版使用模拟模型验证。
