# v0.3.0 活动分析

## 使用流程

1. 导入 FIT / GPX / TCX；CSV 仍为汇总记录。历史文件导入后定位到该文件的活动月份。
2. 点击活动。概览显示时间加权功率、NP、IF、TSS、VI、机械功和功率/心率解耦。
3. “间歇分析”可切换自动努力段、设备圈和已保存手动区间。点击区间起止时间查看相应曲线。
4. “编辑区间”每行填写 `10:00 - 15:00 | 第 1 组`，也支持秒或时:分:秒。按时间排序，不能重叠或超出采样时间。
5. “最佳努力”列出选定持续时间的最大平均功率及发生位置。“路线”使用已有经纬度绘制北向上的离线轨迹，无在线底图。
6. 概览中“修正功率采样”按阈值筛选点。高值并不自动判为错误；核对后可替换或排除单点功率。原始功率保留，可单点或全部还原。
7. “使用计算负荷”主动将当前 TSS 写为已记负荷。导入、修改 FTP 或功率修正均不会擅自改写历史负荷。

## 采样与覆盖率

- 相邻采样采用前值保持，积分范围为 `[当前时间, 下一时间)`；间隔超过 30 秒视为缺口，最后一点不外推。
- 原始测量与修正层分开保存。FIT 暂停期间也保留原始测量，并写入 `timerActive:false`；分析时屏蔽其功率、心率、踏频和速度，坐标保留。活动计时开启的采样才允许功率修正。
- 平均功率、平均心率和机械功按真实有效时间加权；零功率有效，缺失不等于零。
- 活动功率覆盖以有效功率秒数除以完整经过时间。若设备声明的活动时长长于采样跨度，边缘未记录时间也计为缺失。
- 完整一秒内的分数时间按时长加权积分；不完整秒不参与滚动窗口。
- 图表只为显示按时间桶聚合，不改变分析输入。

## 指标

| 指标 | 本地计算方法及条件 |
| --- | --- |
| NP | 完整 30 秒滚动均值的四次方平均后开四次方根；功率覆盖至少 95%，且至少有一个完整窗口 |
| IF | NP / 活动生效 FTP |
| TSS | 有效功率秒数 × NP × IF / (FTP × 3600) × 100；采用活动生效 FTP |
| VI | NP / 时间加权平均功率；均值为零时不报告 |
| 机械功 | 功率时间积分 / 1000，单位 kJ |
| 功率/心率解耦 | 至少 20 分钟完整活动时间，两半各至少 90% 有效功率/心率配对，包含边缘缺采；`(前半P/HR − 后半P/HR) / 前半P/HR × 100%` |
| 最大平均功率 | 仅搜索完整有效窗口，不跨越缺口；活动详情含 5/30/60/300/1200 秒及发生位置 |

不满足条件时保留为空，并在“数据与计算说明”解释原因。解耦受路线、间歇、温度和强度影响；这里计算的是两半功率/心率比的变化，不自动推断其生理原因。

以上为明确的本地实现，未与 Intervals.icu 内部算法逐项对照，也不声称得到所有平台相同的负荷值。设置中可填写历史 FTP 生效记录。活动使用日期当天或之前最近一项；早于首项或没有历史记录时使用当前 FTP。历史记录可影响后续分析，但已保存负荷不会自动改写；主动应用 TSS 时保存 FTP、来源、生效日、NP 和计算时间。当前历史仅支持 FTP，不包含心率及体重历史。

## 自动间歇与分组

默认识别达到 90% 活动生效 FTP 且累计高强度至少 60 秒的努力段；最多连接 15 秒的实测低功率，不连接缺测。设置中可修改强度阈值（30–300%）、累计高强度时间（5–3600 秒）及恢复连接（0–300 秒）。列表不单列恢复段。手动分段和设备圈可分别查看。

同组区间与该组首个成员的时长和均值功率各相差不超过 15%，且功率覆盖至少 95%；至少两项才生成组。它是相似区间的启发式归并，不是自动识别训练类型。

## FIT 边界

使用 `@garmin/fitsdk@21.221.0`，校验头、长度及 CRC。时长保留经过时间，设备计时时长写入备注；计时暂停以缺测边界保留，不压缩时间轴。设备 session 汇总值与时间加权分析可能不同，两者分别保留。

支持标准活动、多个不重叠 session、设备圈、功率/心率/踏频/海拔/距离/速度/坐标。设备圈保留 session 内真实起止边界，边缘缺采通过覆盖率披露。自定义开发字段尚未映射；训练计划类 FIT、不可靠重叠段、存在未归属 session 的采样、无可用采样、超过 36 小时或 150000 个采样的文件明确拒绝，不静默丢弃多余记录。

测试包含已知数值构造文件及 Garmin 官方的合成测试 FIT；后者的 URL 和摘要见 `tests/fixtures/manifest.json`。尚未覆盖所有设备厂商及固件版本。

## 数据兼容

旧数据库和 v1 JSON 备份继续可用；新字段保存设备圈、手动分段、修正层与负荷计算来源。备份恢复会替换本地记录，恢复后定位到最新活动月份。新版本数据请使用新版本备份恢复；旧版应用不保证保留新字段。

## 分布与历史设置

“分布”标签含功率、心率直方图及 FTP 分区。按原始有效阶梯采样时长积分，支持分数秒；应用功率修正，暂停和缺测不计入。功率每 50 W 一档，1000 W 及以上合并；心率按显示区间累计，上界不包含，零功率计入最低档，零心率视为无效。百分比的分母为该指标有效采样时长，不是整场活动时间。

历史 FTP 在设置中每行填写 `YYYY-MM-DD | FTP`，同日不得重复。导出备份保留历史与阈值；旧备份没有这些字段时使用空历史和默认阈值。功率页绝对功率曲线不因 FTP 改变，分区时间则按每项活动生效 FTP 计算。
