# 骑行详情与地图

点开日历中的活动，会在应用主区域打开完整详情页。顶部提供返回入口、编辑与复制；编辑保存后保留当前详情。概览按时间与速度、功率与踏频、心率与训练效果、海拔与环境、设备记录分组。时间序列可限定范围，鼠标在曲线上移动可读取时间、距离、速度、功率、心率和踏频等值。路线支持平移、缩放、适配和轨迹悬停。

## FIT 字段和来源

新增保留设备经过/计时/移动时间、平均/最高速度、爬升/下降、功率/心率/踏频均值与极值、海拔与温度、热量、机械功、训练效果、左右平衡和设备信息。实际可用项取决于 FIT；没有提供的字段不造值。每项显示“设备记录”“采样计算”“推算”或“已保存”。

速度在文件中以 m/s 保存，在界面统一转换为 km/h。缺速度但有相邻有效累计距离或 GPS 时，按距离差/时间差推算；暂停、超过 30 秒的缺口和距离回退均不跨越。采样均值按有效时间加权，最后一点不向后外推；设备汇总优先。移动时间推算以速度大于 1.8 km/h 为阈值，只覆盖有效采样，不能补齐未记录路段。

爬升推算为相邻有效海拔增量累加，没有平滑，可能受海拔噪声影响。v0.8.0 增加功率采样能耗估算（效率假设与覆盖率明确标注），厂商训练效果仍只呈现设备数值。更多补算、有效公里/设备圈和分布说明见 [INFERENCE.md](INFERENCE.md)。设备平均功率与应用已保存修正后计算的 NP / TSS / 机械功分别展示，可能不同；已记负荷仅在用户主动应用后更新。

## 补充旧 FIT

旧活动已有的速度采样可直接显示。要取得此前未保存的设备汇总等新字段，再次选择同一 FIT 文件，确认“补充 FIT 骑行详情”。补充保留原活动 ID、名称、备注、用户已有数值、原采样、功率修正、目标、器材与计划关联，只填缺失的新字段。

新版导入保留文件哈希及活动段序号；历史导入按完整原始基础采样唯一匹配。匹配不可靠、原始采样已修改、活动段缺失或候选重复时整体拒绝，不会凭名称或日期猜测替换。普通重复导入仍不生成第二条活动。

## 地图与离线

底图需用户点击“加载地图底图”后联网按当前视野加载；默认只读本机缓存。联网请求包含当前视野的瓦片坐标，不上传 FIT。浏览过且允许缓存的瓦片存于本机 data/map-tiles；关闭联网或重启后可离线复用，未缓存区域保留轨迹并提示无底图。地图缓存不包含在 JSON 训练备份中，当前没有整区域下载功能。

默认使用 Esri 简约浅色底图，可切换 OpenTopoMap 地形底图，地图中显示对应来源署名。路线采用 WebMercator 投影，支持跨日界线处理；速度按 0–60+ km/h 连续插值着色，相邻轨迹端点间使用渐变，缺测显示灰色。平移时复用已有轨迹与瓦片图层，松手后刷新视野。
