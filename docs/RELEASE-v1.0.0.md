# Cycle 1.0.0

2026-11-11 · 首个正式版本 · macOS Apple Silicon

## 界面

统一侧栏、顶栏、卡片、按钮、表单、表格和弹窗的视觉风格。活动日历、体能、功率、训练库、周期计划、比较、健康状态、目标与器材、设置，以及活动详情各标签均使用同一套设计。浅色和深色模式同步更新，适配 960 像素及以上桌面窗口。

清理各页面重复的防御性声明与开发过程说明，用简短直接的文案解释功能。删除、覆盖与备份恢复保留清楚的操作确认，估算数值保留来源与估算标识。

## 训练工作空间

正式版包含活动文件导入、活动曲线与分段分析、NP/IF/TSS、单活动 FTP 估计、VO₂max 估计、路线与天气、结构化训练、多周计划、健康图表、器材维护和目标管理。

健康 ZIP/XML 导入支持类型与日期选择、图表预览、重复更新和临时文件清理。健康页面以图表浏览指标，支持类型搜索、展开与收起。

## 升级与数据

应用沿用 `local.cycle.training` 标识和既有本机数据目录。v0.15.0 的活动、健康数据、计划、器材、目标和设置可继续使用；用户记录与备注保持原样。
