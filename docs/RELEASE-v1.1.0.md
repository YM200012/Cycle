# Cycle 1.1.0

2026-11-16 · 桌面界面与 AI 活动复盘 · macOS Apple Silicon

## 更适合训练数据的界面

侧栏、顶栏、日历、表格、表单和活动详情采用更紧凑的布局。中性灰背景、细分隔线和小圆角取代大面积彩色块与重复阴影，关键数值和曲线成为页面中心。

浅色和深色同步调整，保留功率、心率、速度、踏频和训练分区的颜色含义。活动详情继续采用应用内完整页面，图表缩放、地图和训练编辑等操作沿用既有流程。

## AI 活动复盘

设置中可以连接 OpenAI 兼容 API、读取模型目录并选择复盘模型。当前预设服务为 `https://api.dsstl.xyz/v1`，模型由用户选择后保存。

已完成活动新增“AI 复盘”入口。生成前显示服务地址、模型和完整训练摘要，用户可填写关注问题，再点击发送。复盘围绕本次训练、值得关注的表现和下一步建议展开。

训练指标由本机计算，模型用于解释。摘要只包含选中活动的数值训练信息、FTP 基准、最佳努力与区间，排除姓名、活动名称、日期、备注、GPS、原始采样和 Apple 健康记录。模型建议不直接改动 FTP、活动或计划。

API 密钥独立保存在本机，不回显、不进入训练备份。活动数值或模型设置在预览后变化时，需要重新查看摘要再发送。
